# Contributing

Run `scripts/test.sh` and `scripts/build.sh` before submitting a change. Keep
host-specific settings and secrets under `.local/`, not in source files.

General scene artwork requires provenance and redistribution information in
`frontend/artwork/SOURCES.md`. Commercial game data is never accepted. Optional
game integrations belong behind the documented extension boundary.

Unless explicitly agreed otherwise, submitted software, configuration,
scripts, and documentation are contributed under Apache-2.0. Submitted
project artwork must be original or otherwise redistributable under CC BY 4.0
and must include a provenance record. Do not submit third-party media without
documented source URLs and terms compatible with its intended use.
